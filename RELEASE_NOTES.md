# Bacterial pseudogene annotation benchmark v1.0.0

Research software and derived-data snapshot prepared by Gurgen Karapetyan and Astghik Pepoyan. The unpublished manuscript is not included in this repository.

- 523 complete bacterial RefSeq genome assemblies analysed under PGAP, Pseudofinder applied to PGAP, Bakta and DFAST configurations.
- All five original source figures (PDF, PNG, SVG), original figure-data tables and complete Supplementary Tables S1–S9/S7b.
- Research analysis code, validation tests, relevant result summaries and frozen study protocols.
- No claim of biological correctness ranking of annotation configurations.
- Twelve large intermediate TSV files are not stored in this GitHub snapshot. They are listed under LARGE_INTERMEDIATE_DATA.md and must be archived separately as a complete research-data deposit.

This release is a software and research-output snapshot, not acceptance or publication of the associated journal article. A DOI should only be added after Zenodo assigns it.
